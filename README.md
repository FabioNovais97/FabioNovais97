## Projetos

### [Loja Veloz](https://github.com/FabioNovais97/loja-veloz)
Projeto acadêmico de uma plataforma de pedidos baseada em microsserviços, com serviços separados para pedidos, estoque e pagamentos. Inclui API Gateway, PostgreSQL, Docker, Kubernetes, CI/CD e observabilidade.

**Tecnologias:** Python, FastAPI, PostgreSQL, Docker, Kubernetes, Prometheus, Grafana e OpenTelemetry.

### [Cristoteca Todos os Santos](https://github.com/FabioNovais97/cristoteca-todos-santos)
Aplicação web para gerenciamento de pedidos e ingressos de eventos. O repositório contém frontend em React e uma API em FastAPI, com módulos para pedidos, pagamentos e validação de ingressos.

**Tecnologias:** React, Vite, Python e FastAPI.

### [Controle de Gastos](https://github.com/FabioNovais97/ControleGastos)
Aplicativo mobile para registrar despesas, organizar gastos por categoria e acompanhar o total acumulado. Os dados são armazenados localmente no dispositivo.

**Tecnologias:** React Native, Expo, TypeScript e AsyncStorage.

### [Ficha TLC](https://github.com/FabioNovais97/ficha-tcl)
Aplicação web com formulário e fluxo de envio e retorno de informações.

**Tecnologias:** Python, Flask e JavaScript.
